Introduction

LASTSYNC is an offline survival system. It runs on your own computer, keeps working when the internet and the phone network are down, and keeps your household in touch over local Wi-Fi.

Set it up while you are still online: fill in your plan, save your town's map, download the encyclopedia and an AI model. When the network goes down, everything you saved still works, from search and maps to group check-ins and the crypto relay.

Offline crypto relayCarry signed Bitcoin and Solana transactions phone to phone, and send them the moment any device finds a signal. Offline street mapsReal streets, buildings and emergency places. Save an area once and use it with no signal. Search and AskAnswers quoted from your saved guides, with citations. It says so when it doesn't know. Household check-insPhones scan a QR code and send I'm safe, Meet here or I need help over local Wi-Fi.

Principles

  • Local first. Everything runs on your machine at http://localhost:8787. There is no account and no cloud service.
  • Honest answers. Ask only answers from what you saved, quotes its source, and says when it can't help.
  • Your keys stay yours. The relay only carries transactions that are already signed. It never asks for, stores or uses a private key.
  • Open source. Every file is public under the MIT license, and every running copy shows the commit and file fingerprints it uses.

Quick start

Three ways to run LASTSYNC. They all use the same code.

Windows (portable)

  1. Download LASTSYNC-windows.zip from the latest release.
  2. Unzip it anywhere, including a USB drive.
  3. Double-click LASTSYNC.exe. Your browser opens at http://localhost:8787.

Your data is kept in the data folder next to the program, so the whole thing travels on a USB drive.

From source

Requires Node.js 20 or newer (22.13 or newer to read imported MBTiles maps). There are no npm dependencies to install.

git clone https://github.com/HuffyDev/sync.git
cd sync
npm start

Then open http://localhost:8787. Set PORT to change the port and LASTSYNC_DATA to choose where data is stored.

Online demo

Try it in the browser first: open the app. Each visitor gets a private workspace, kept for 7 days. Use the offline app for anything you want to rely on.

First things to do

  1. My plan: add contacts, meeting points and your grab list. Print the one-page sheet.
  2. Maps: find your town and choose Save this area.
  3. Encyclopedia: download the 64 articles.
  4. On-device AI: download a model if your computer has a graphics chip with WebGPU.
  5. Readiness: check what's still missing.

How it works

One computer runs LASTSYNC. Everyone else connects to it over the local network.

Your computerruns LASTSYNC on port 8787
Wi-Fi router or hotspotworks without internet while it has power
Phonesjoin in the browser by QR code

The computer at localhost gets the full app. Phones on the same network get a smaller page with check-ins, messages, the status board, the relay, guides and the outage log. A Wi-Fi router keeps working with no internet as long as it has power; a power bank or UPS can run one for hours. With no router, turn on Mobile hotspot in Windows.

Where your data lives

Everything is stored as plain files in the data folder: your plan, notes, pins, routes, saved maps, downloaded articles and the relay queue. Nothing is sent anywhere unless you use a feature that needs the internet, such as saving a map area or broadcasting a transaction.

Crypto relay

Send crypto with no internet. Sign a transaction in your own wallet, and LASTSYNC carries it until any device in your group finds a signal.

  1. Sign it offline, in your own wallet. LASTSYNC never sees your keys.
  2. Add it to LASTSYNC. Paste it or scan its QR code. LASTSYNC decodes it and shows who gets paid and how much, and checks the signatures.
  3. The group carries it. It is shared with every phone in your local group.
  4. First signal sends it. Whichever device gets a connection first, the computer or any phone, broadcasts it. LASTSYNC then follows it to confirmation.

Supported

NetworkFormatWhat LASTSYNC reads
BitcoinRaw transaction hexInputs, outputs and addresses (legacy, SegWit, Taproot), amounts, fee when known, txid
SolanaBase64 or base58, legacy or v0SOL transfers, SPL token transfers, memos, fee payer, durable nonce, Ed25519 signatures
Only signed transactions are accepted. LASTSYNC can't create, change or sign a transaction. It checks, stores, shares and broadcasts exactly what your wallet produced.

You can read every line of the relay in server/relay.js.

Bitcoin

Bitcoin transactions don't expire, so a signed one can be carried for as long as you need.

Signing offline

Use a wallet that can sign without a connection, such as Sparrow or Electrum on an offline computer, or a hardware wallet. Create the transaction while you still know your coins (or use a watch-only wallet), sign it, and export the raw transaction hex.

Adding it

  1. Open Crypto relay in the app.
  2. Paste the hex, or use Scan QR with the camera.
  3. Check the decoded outputs: every address and amount is shown before you queue it.
  4. Choose Add to relay. Add a note if it helps the group.

Fees

The fee is fixed when you sign. If the network is busy when a signal returns, a low fee can take a long time to confirm, so pick a fee that allows for that.

Solana

To send Solana offline, sign with a durable nonce. A normal transaction expires about a minute after it is signed.

Durable nonces

A Solana transaction includes a recent blockhash, which goes stale within about 150 blocks. A durable nonce account replaces the blockhash with a stored value, so the transaction stays valid until that nonce is used. Set up a nonce account while you are online, then sign transfers against it when you are not.

solana create-nonce-account nonce-keypair.json 0.0015
solana transfer <RECIPIENT> 0.5 --sign-only \
  --nonce <NONCE_ACCOUNT> --nonce-authority <KEYPAIR> \
  --blockhash <NONCE_VALUE>

LASTSYNC tells you which kind it received. Transactions with a durable nonce show Uses a durable nonce. Others show a warning that they will expire.

What is decoded

  • System program SOL transfers, with amounts in SOL.
  • SPL Token Transfer and TransferChecked, including the mint and decimals when present.
  • Memo instructions.
  • The fee payer and every signature, each verified with Ed25519 before the transaction is queued.

Broadcasting and status

The computer tries every 20 seconds while anything is waiting. Phones with mobile data can send a transaction themselves.

Statuses

StatusMeaning
Waiting for signalChecked and queued. It will be sent on the next connection.
BroadcastAccepted by the network. LASTSYNC is waiting for a confirmation.
ConfirmedIncluded in a block.
ExpiredA Solana blockhash went stale. Sign it again with a durable nonce.
RejectedThe network refused it, for example because the coins were already spent. The reason is shown.

From a phone

On a phone in the group, open the Relay tab. Any waiting transaction has Broadcast from this phone, which sends it directly over the phone's own mobile data and reports the result to the group.

Endpoints

Bitcoin uses the mempool.space API and Solana uses the public mainnet RPC. Point them elsewhere, including your own node, with LASTSYNC_BTC_API and LASTSYNC_SOLANA_RPC. See Configuration.

Search and Ask

Search everything you saved. Ask answers from it, with citations.

Search

Search covers the 22 bundled guides, your documents and PDFs, notes, pins and the encyclopedia. It ranks with BM25 and understands survival synonyms, so cleaning water finds disinfecting. Results jump to the exact section, PDF page or note, and can be filtered by topic, pack and type.

Ask

Ask works with no model at all: it finds the best-matching section and quotes it as written, then lists related sections. It never stitches sentences from different sources together, because mixing a bleach dose for surfaces into drinking-water instructions is exactly the kind of mistake that hurts people.

With a model connected, Ask writes the answer from the passages it found and cites each one with a number. If the saved sources don't cover the question, it says so.

If a question sounds like an emergency, Ask shows your local emergency numbers first.

On-device AI

Three models that run inside the browser on your computer's own graphics chip. No server and no account.

ModelDownloadGood for

Models need a browser with WebGPU, such as a recent Chrome or Edge. They download once and are then stored by the browser for offline use. Ask sends the model only the passages it retrieved, and the model has to cite them.

Maps and GPS

A full street map that keeps working with no signal.

Saving an area

Every area you view while online is cached on your computer. To be sure, move the map to your town and choose Save this area: LASTSYNC estimates the size, then downloads it down to street level. Offline, the map uses saved areas first, then a built-in world map.

What's on the map

Streets with names, buildings (in 3D when tilted), water, parks, places, and emergency places: hospitals, pharmacies, police, fire stations, drinking water, shelters and fuel. Turn layers on and off from the layers panel.

Tools

  • Pins and routes, with walking time. Import routes from GPX.
  • Measure distance and bearing between points.
  • Range rings around any point.
  • Search across pins, places, streets and coordinates.
  • Right-click anywhere for coordinates and quick actions.
  • Follow, rotate, tilt, north-up and full screen.

GPS

Use the device's location, or plug in a USB GPS receiver and connect it with USB GPS, which reads standard NMEA sentences. A USB receiver needs no network at all. Phones on the local http:// address can't use their own GPS because browsers require https for it; they mark their location by tapping the map instead.

Imported maps

Raster MBTiles files (PNG, JPG or WebP tiles), for example made in QGIS or received in a pack, can be added as overlays. Map data © OpenMapTiles © OpenStreetMap contributors, served by OpenFreeMap.

Encyclopedia

64 survival-relevant Wikipedia articles, saved for offline reading.

Topics cover medicine, water, food, sanitation, shelter, power, navigation and communications, and disasters. Download them once while online; after that you can read, search and ask about them with no internet, and phones in your group can read them too. Article text is CC BY-SA 4.0, and image credits are kept.

Library

22 bundled field guides, plus anything you add.

Guides cover water, power, food, first aid, shelter, sanitation, communications and emergency kits. Each one shows its publisher, date, version and sources. Add your own PDFs, text and Markdown files, and write notes. Everything you add is searchable and can be used by Ask.

Household plan

Who to contact, where to meet, and what to grab.

The plan holds contacts, meeting points with map locations, responsibilities, and grab, go and check-on checklists. It saves as you type.

Printable sheet

My plan › Printable sheet fits everything on one page: contacts, meeting points, a small map, checklists and quick facts. Print it and keep a copy somewhere that doesn't need power.

Gear and readiness

Gear

27 items across power, water, medical, communications, light and fire, shelter, food, tools and documents. Each explains why you need it, what to look for and a rough price. Mark what you have to get an essentials score.

Readiness

Readiness checks what is actually saved: guides, map areas, routes, an AI model, your plan and whether it's printed, pack dates, free disk space, the gear score and the local network. Each missing item links to where you fix it.

Local groups

Your computer hosts the group. Phones join in their browser; nothing to install.

  1. Open Group and choose Start a session.
  2. Phones on the same Wi-Fi scan the QR code, or open the address shown and type the invite code.
  3. Each person enters a name and is in.

The invite code is required, attempts are rate-limited, and you can make a new code or remove a member at any time. Phones only see the group, guides, the encyclopedia, map tiles and the relay, never your notes, plan, documents or settings.

In the online demo

Invites are links. Anyone who opens one joins your group as a guest with the same limited access as a phone on Wi-Fi.

Status board and outage log

Status board

Shows who has checked in, when you last heard from each person, and the current meeting point.

Outage log

A shared record of what happened, what has been checked and what still needs doing. It updates live on every device, so someone else can take over.

Packs

Bundle guides, documents, notes, pins, routes and maps into one .lspack file to share by USB.

Every file in a pack has a SHA-256 hash, and a pack can be signed with an Ed25519 publisher key. Before installing, LASTSYNC checks every hash offline, and signed packs must match a publisher you trust. A changed or damaged pack is refused.

Publishing

Create a publisher key in Packs to sign the packs you export. Share your public key with the people who'll install them so they can add you as trusted.

Install and offline use

The app installs like a normal program from the browser and keeps working offline.

Choose Install app in the status bar, or your browser's install option. The app's files are cached by a service worker. Save for offline use also stores the guides, the encyclopedia and your plan in the browser, so Search and Ask keep working even if the computer running LASTSYNC can't be reached.

The app talks to its server over a small JSON API. You can use it for your own tools.

Requests from the computer itself have full access. Group members have the routes marked member. Write requests must send content-type: application/json.

The full list is in server/index.js.

curl -s http://localhost:8787/api/relay/decode \
  -H 'content-type: application/json' \
  -d '{"tx":"0200000001..."}'

Access model

Who can see what.

  • The computer running LASTSYNC (localhost) gets the full app. The server checks the Host header, so other websites can't reach it through your browser, and write requests must be JSON.
  • Phones on the network need the invite code, then hold a session cookie. They get the join page, the bundled guides, the encyclopedia, map tiles, the group and the relay.
  • The page is served with a strict Content-Security-Policy: no inline scripts, and only the hosts listed for maps, models and broadcasting.
  • Packs are checked file by file before install.

Open source

LASTSYNC is free and open source under the MIT license.

The code is at github.com/HuffyDev/sync. It has no npm dependencies. Third-party browser libraries are included as files in web/vendor, with their licenses in NOTICES.txt.

Checking a running copy

Every running copy has an Open source page that shows the exact commit and a SHA-256 fingerprint for every file in server, web and content, plus one combined fingerprint. Compare it with a copy you build yourself:

git clone https://github.com/HuffyDev/sync.git
cd sync
npm run hashes

If the combined fingerprints match, the copy is running exactly that code. The same data is available at GET /api/source.

FAQ

Does LASTSYNC need the internet?

Only to set things up: saving map areas, downloading the encyclopedia or an AI model, and broadcasting transactions. Everything else works offline.

Can LASTSYNC move my crypto?

No. It can only carry and broadcast transactions your own wallet has already signed. It never asks for, stores or uses a private key, and it can't change a transaction.

Why did my Solana transaction expire?

It used a recent blockhash, which goes stale in about a minute. Sign it again with a durable nonce. See Solana.

Do phones need an app?

No. They join in the browser by scanning the QR code, on the same Wi-Fi as the computer.

Does it run on Mac or Linux?

Yes, from source with Node.js 20 or newer. The portable download is for Windows.

How long does a laptop last in a blackout?

LASTSYNC uses very little power on its own. Lower the screen brightness, close other programs, and charge from a power bank or car when you can. The status bar shows the battery level.

Is it free?

Yes. It's free and open source under the MIT license.
